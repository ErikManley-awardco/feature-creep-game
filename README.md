# Feature Creep

Web-first implementation of Feature Creep: a snake survival game where a new random feature is added every 30 seconds.

## Current Status
- Step 0 complete: setup and alignment docs.
- Step 1 in progress: deterministic core foundation is implemented.

## Commands
- `npm run dev` starts local development.
- `npm run build` creates production build.
- `npm test` runs deterministic core tests.
